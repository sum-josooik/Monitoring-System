레이어 설정 — 레이어별 이름·색상·토픽 지정, ＋로 추가
차량 위치 — 데이터 좌표계(multi_lidar_merge output_frame) 기준 차체

기본값은 multi_lidar_merge 의 remove_vehicle 영역(x −1.3~1.7, y −2.5~5.7, 전방 +y)입니다. 거리·방위·근접 경고·주행 뷰가 모두 이 차체를 기준으로 계산됩니다.

주행 뷰 — RViz 패널의 3D 주행 · 2D 레이더 탭

차선 인식 토픽(이름에 lane)이 없으면 조향각·조향비·축거로 계산한 예상 경로를 차로로 그립니다.

주행 뷰 카메라 — 영상 위를 클릭하면 크게 보기

Camera Preview 슬롯에 열려 있는 카메라 영상을 재사용합니다(브라우저 연결 추가 없음). 슬롯에 없는 카메라는 표시되지 않습니다. 차량 둘레 배치는 토픽 이름(Front / Left / Right / Rear / avm)으로 위치를 정합니다.

감싼 차로 수
  • 맞추는 순서: 곧은 도로에서 화면 정지 → 소실점을 끌어 파란 연장선을 차선에 겹치기 → 왼쪽 미리보기에서 차선이 세로로 나란한지 확인.
  • 꼭짓점을 차선 위에 정확히 올릴 필요는 없습니다. 미리보기가 기준입니다.
  • 도로 전체를 감싸되 잔디·하늘·차체는 빼세요.
  • 폭·거리는 미리보기의 눈금(가로 3.5 m, 세로 5 m)이 실제 차로 폭·점선 길이와 맞게 조정하세요.
  • 측면 카메라는 차선이 미리보기에서 가로로 나란하면 맞습니다. 어안 렌즈라 끝부분이 조금 휘는 것은 정상입니다.
보정값 적용
새 창으로 열기

화면 설정(레이아웃·헤더·Bag·RViz·주행 뷰·카메라·Vehicle 카드·대시보드)과 서버에 저장된 값(Bag 저장 경로, 탭별 보정 적용, 카메라 보정값과 보관 폴더, 차선 인식 범위)을 JSON 파일로 저장하거나 불러옵니다. 파일 위치: ~/captin5_ws/src/ros_web_monitor/UI

현재 화면 구성을 "기본값"으로 저장해두면, 언제든 한 번에 되돌릴 수 있습니다. 기본값과 UI 폴더 설정은 화면 설정만 다루며, 서버에 저장된 값은 바꾸지 않습니다.

녹화 파일과 재생 목록이 저장되는 폴더입니다. 절대 경로로 입력하거나 찾아보기로 선택하세요. 녹화·재생 중에는 변경할 수 없습니다.

⌕

Bag 재생

저장된 bag을 선택해 재생합니다. ROS1(.bag)·ROS2(폴더) 모두 지원하며, 재생된 토픽은 /bagplay/... 네임스페이스로 격리되어 실시간 데이터와 섞이지 않습니다. 재생을 시작하면 자동으로 Play 뷰로 전환됩니다.
