모델 켠 모델만 GPU 를 씁니다

    sunnypilot 주행 모델(비전 + 정책)을 버스 전방 카메라 영상으로 돌립니다. 차량은 제어하지 않습니다.

    카메라 장착

    모델 입력 영상에서 수평선(노란 점선)이 실제 지평선·먼 바닥 끝과 겹치도록 숙임 값을 맞추세요. 모델은 높이 1.22 m 카메라를 전제로 학습됐습니다.

    모델 입력 영상 + 예측

    예측 뷰어

    드래그 회전 · 휠 확대 · 더블클릭 초기화

    모델 추가

    sunnylink.wiki 의 카테고리에서 모델을 골라 내려받습니다. 받은 뒤 이 장치용 엔진으로 변환하며(모델당 수 분), 끝나면 왼쪽 모델 목록에 나타납니다. 원본(ONNX)이 공개된 모델만 변환할 수 있습니다.

    Bag 불러오기

    저장된 Bag 을 고르면 재생을 시작하고, 모델 입력을 그 Bag 의 전방 카메라 영상으로 바꿉니다. 재생 데이터는 /bagplay/... 로 분리되어 실시간 데이터와 섞이지 않습니다.
